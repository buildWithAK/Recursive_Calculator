# Recursive Calculator

A command-line calculator built in Python that performs basic arithmetic operations and allows users to continue calculations using previous results. The project demonstrates the use of functions, dictionaries, loops, user input handling, and recursion to create a seamless calculator experience.

## Features

* Addition, subtraction, multiplication, and division operations
* Function-based operation handling
* Dictionary mapping operators to functions
* Continuous calculations using previous results
* Start a new calculation at any time
* Exit option for ending the program gracefully
* Division-by-zero protection
* Recursive program restart functionality

## Technologies Used

* Python 3

## Concepts Practiced

* Functions
* Dictionaries
* Loops and conditionals
* User input validation
* Recursion
* Modular programming
